# Преследователь

Используя базовые объекты **Unity** напишите передвижение для персонажа используя `CharacterController`

А также передвижение для бота используя `Rigidbody`

Бот преследует игрока, но не подходит вплотную к нему и имеет скорость меньшую чем у игрока

Обязательно добавить: 
- небольшую ступеньку
- подъём
- спуск

Игрок и бот их всех могут преодолевать одинаково
